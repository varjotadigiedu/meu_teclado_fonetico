# Pasta de Áudios dos Nomes das Letras

Coloque aqui os arquivos MP3 com o nome de cada letra do alfabeto.

## Nomeação dos arquivos

Os arquivos devem ser nomeados com a letra em minúsculo:

- `a.mp3` - nome da letra "á"
- `b.mp3` - nome da letra "bê"
- `c.mp3` - nome da letra "cê"
- `d.mp3` - nome da letra "dê"
- `e.mp3` - nome da letra "é"
- `f.mp3` - nome da letra "éfe"
- `g.mp3` - nome da letra "gê"
- `h.mp3` - nome da letra "agá"
- `i.mp3` - nome da letra "i"
- `j.mp3` - nome da letra "jota"
- `k.mp3` - nome da letra "cá"
- `l.mp3` - nome da letra "ele"
- `m.mp3` - nome da letra "eme"
- `n.mp3` - nome da letra "ene"
- `o.mp3` - nome da letra "ó"
- `p.mp3` - nome da letra "pê"
- `q.mp3` - nome da letra "quê"
- `r.mp3` - nome da letra "erre"
- `s.mp3` - nome da letra "esse"
- `t.mp3` - nome da letra "tê"
- `u.mp3` - nome da letra "u"
- `v.mp3` - nome da letra "vê"
- `w.mp3` - nome da letra "dáblio"
- `x.mp3` - nome da letra "xis"
- `y.mp3` - nome da letra "ípsilon"
- `z.mp3` - nome da letra "zê"

## Observação

Se algum arquivo MP3 não existir, o sistema usará automaticamente a síntese de voz (TTS) do navegador como fallback.
