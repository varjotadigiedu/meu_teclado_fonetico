# Pasta de Áudios dos Fonemas

Coloque aqui os arquivos MP3 com o som de cada fonema.

## Nomeação dos arquivos

Os arquivos devem ser nomeados exatamente como o símbolo do fonema:

### Vogais Orais (7)
- `a.mp3` - som do fonema /a/ (ex: mar)
- `e.mp3` - som do fonema /e/ fechado (ex: medo)
- `ɛ.mp3` - som do fonema /ɛ/ aberto (ex: pé)
- `i.mp3` - som do fonema /i/ (ex: vida)
- `o.mp3` - som do fonema /o/ fechado (ex: doce)
- `ɔ.mp3` - som do fonema /ɔ/ aberto (ex: pó)
- `u.mp3` - som do fonema /u/ (ex: tudo)

### Vogais Nasais (5)
- `ã.mp3` - som do fonema /ã/ (ex: fã)
- `ẽ.mp3` - som do fonema /ẽ/ (ex: sento)
- `ĩ.mp3` - som do fonema /ĩ/ (ex: lindo)
- `õ.mp3` - som do fonema /õ/ (ex: ponte)
- `ũ.mp3` - som do fonema /ũ/ (ex: mundo)

### Consoantes Oclusivas (6)
- `p.mp3` - som do fonema /p/ (ex: pato)
- `b.mp3` - som do fonema /b/ (ex: bola)
- `t.mp3` - som do fonema /t/ (ex: tempo)
- `d.mp3` - som do fonema /d/ (ex: dado)
- `k.mp3` - som do fonema /k/ (ex: casa)
- `g.mp3` - som do fonema /g/ (ex: gato)

### Consoantes Fricativas (6)
- `f.mp3` - som do fonema /f/ (ex: faca)
- `v.mp3` - som do fonema /v/ (ex: vela)
- `s.mp3` - som do fonema /s/ (ex: sapo)
- `z.mp3` - som do fonema /z/ (ex: zebra)
- `ʃ.mp3` - som do fonema /ʃ/ (ex: chave)
- `ʒ.mp3` - som do fonema /ʒ/ (ex: jacaré)

### Consoantes Nasais (3)
- `m.mp3` - som do fonema /m/ (ex: mala)
- `n.mp3` - som do fonema /n/ (ex: navio)
- `ɲ.mp3` - som do fonema /ɲ/ (ex: banho)

### Consoantes Líquidas (4)
- `l.mp3` - som do fonema /l/ (ex: laranja)
- `ʎ.mp3` - som do fonema /ʎ/ (ex: folha)
- `r.mp3` - som do fonema /ɾ/ brando (ex: caro)
- `R.mp3` - som do fonema /ʁ/ forte (ex: rato)

## Observação

Se algum arquivo MP3 não existir, o sistema usará automaticamente a síntese de voz (TTS) do navegador como fallback.
